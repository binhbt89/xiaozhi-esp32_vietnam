================================================================================
                           ARCHITECTURE OVERVIEW
================================================================================

This service wraps the official Zing MP3 API (https://zingmp3.vn).

Key Features:
- Uses HMAC-SHA512 signature for API authentication
- Automatic cookie management for session handling
- Proxies all requests through the Node.js server

1. GET HOME PAGE
--------------------------------------------------------------------------------
Endpoint:   GET /api/home
Description: Get home page data with featured content, playlists, etc.

  "msg": "Success",

6. GET SONG (STREAMING URL)
--------------------------------------------------------------------------------
Endpoint:   GET /api/song
Description: Get streaming URLs for a song

Query Parameters:
  - id (required) : Zing MP3 song ID (encodeId)

Response Success:
{
  "err": 0,
  "msg": "Success",
  "data": {
    "128": "https://...",     // 128kbps MP3 URL
    "320": "https://...",     // 320kbps MP3 URL (VIP)
    "lossless": "https://..." // FLAC URL (VIP)
  }
}

Response Error:
{
  "error": "Missing id"
}

Example:
  GET /api/song?id=ZW6AOCAZ

Note: 320kbps and lossless require VIP account (may return VIP error)

--------------------------------------------------------------------------------
7. GET SONG STREAM (REDIRECT)
--------------------------------------------------------------------------------
Endpoint:   GET /api/song/stream
Description: Redirect directly to stream URL (for audio playback)

Query Parameters:
  - id      (required) : Zing MP3 song ID
  - quality (optional) : Quality - '128', '320', 'lossless' (default: '128')

Response:
  - HTTP 302 Redirect to the stream URL

Response Error:
{
  "error": "Stream URL not found for quality [quality]"
}

Example:
  GET /api/song/stream?id=ZW6AOCAZ&quality=128

Use Case:
  Direct playback in <audio> HTML elements or embedded players

================================================================================
                           ERROR HANDLING
================================================================================

All endpoints return consistent error responses:

HTTP 400 - Bad Request (Missing parameters):
{
  "error": "Missing [parameter_name]"
}

HTTP 500 - Internal Server Error:
{
  "error": "Error message description"
}

Zing MP3 API Error Codes (in response body):
{
  "err": -1,
  "msg": "Error message"
}

Common error codes:
- err: 0   = Success
- err: -1  = General error
- err: -201 = Content not available
- err: -301 = VIP required (for 320kbps/lossless)

================================================================================
                         INTERNAL METHODS (ZingMp3Api Class)
================================================================================

The ZingMp3Api class in dist/index.js provides these internal methods:

Authentication:
- getHash256(str)           : SHA-256 hash
- getHmac512(str, key)      : HMAC-SHA512 signature
- hashParam(path, id)       : Generate signature with ID
- hashParamNoId(path)       : Generate signature without ID
- hashParamHome(path)       : Generate signature for home page
- hashCategoryMV(path,id,type) : Generate signature for MV category
- hashListMV(path,id,type,page,count) : Generate signature for MV list

HTTP:
- getCookie()               : Get session cookie from Zing MP3
- requestZingMp3(path, qs)  : Make authenticated request to Zing MP3

Public Methods:
- getSong(songId)           : Get streaming URLs
- getDetailPlaylist(playlistId) : Get playlist details
- getHome()                 : Get home page
- getTop100()               : Get Top 100 playlists
- getChartHome()            : Get chart data
- getNewReleaseChart()      : Get new releases
- getInfoSong(songId)       : Get song info
- getListArtistSong(artistId, page, count) : Get artist songs
- getArtist(name)           : Get artist page
- getLyric(songId)          : Get lyrics
- search(name)              : Search all content
- getListMV(id, page, count): Get MV list by genre
- getCategoryMV(id)         : Get MV category
- getVideo(videoId)         : Get video/MV details

================================================================================
                              NOTES
================================================================================

1. All streaming URLs from Zing MP3 are time-limited and will expire.

2. 320kbps and lossless quality require a VIP subscription.
   Without VIP, only 128kbps is available.

3. Use /api/song/stream for direct audio playback to avoid CORS issues.

4. Cookie session is automatically managed by the ZingMp3Api class.

5. The CTIME parameter is generated server-side using current timestamp.
